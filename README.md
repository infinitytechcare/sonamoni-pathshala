# সোনামণির পাঠশালা 📚⭐

ছোট্ট সোনামণির ১৫ দিনের পরীক্ষা-প্রস্তুতির Android অ্যাপ। পুরো অফলাইন, কোনো বিজ্ঞাপন নেই।

## কী কী আছে
- **বাংলা সংখ্যা ১–৫০** ও **ইংরেজি সংখ্যা 1–50** (আলাদা আলাদা) — অ্যাপ সংখ্যা উচ্চারণ করে, বাবু শুনে ঠিক সংখ্যাটা বেছে নেয়; সোজা ক্রম, পরেরটা কী, লেখা, ছড়া
- **ইংরেজি A–Z** — বড়/ছোট হাতের অক্ষর, প্রতিটি অক্ষরে ২টি শব্দ ও বাংলা অর্থ (A-তে Apple মানে আপেল), ABC ছড়া
- **বাংলা বর্ণমালা অ–ঁ** — স্বরবর্ণ ১১ + ব্যঞ্জনবর্ণ ৩৯, ছবি দিয়ে শব্দ, বর্ণের ছড়া
- **আরবি হরফ আলিফ–ইয়া** — ২৯টি হরফ, নাম, একটি করে শব্দ ও অর্থ
- **দোয়া ও সূরা** — সূরা ফাতিহা, সূরা ইখলাস (তিলাওয়াতসহ), ঘুমানো/ঘুম থেকে ওঠা/ইস্তেঞ্জার দোয়া, কালেমা তাইয়্যেবা, শাহাদাত, তাওহীদ — "মুখস্থ যাচাই" মোডসহ
- **মাসআলা** — ওজুর ফরজ ৪, নামাজের ফরজ ১৩, গোসলের ফরজ ৩
- **পরিচ্ছন্নতা ও স্কুল** — বাবা/মা প্রতিদিন টিক দেবেন
- **১৫ দিনের রুটিন**, **মডেল টেস্ট (১০০ নম্বর)**, **মৌখিক পরীক্ষার মহড়া** (বাবা/মা পরীক্ষক)
- বাংলা / English ইন্টারফেস

## উচ্চারণ
ফোনের Google Text-to-Speech দিয়ে পড়ে শোনায়। বাংলা ভয়েস না থাকলে অ্যাপের ⚙️ সেটিংস থেকে "ভয়েস সেটিংস খুলুন" চেপে বাংলা (বাংলাদেশ) ও আরবি ভয়েস ডাউনলোড করুন।

## বিল্ড
`main` ব্রাঞ্চে push করলে GitHub Actions নিজে থেকে APK বানিয়ে **Releases**-এ দেয়।
দরকারি Secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD` (ঐচ্ছিক: `KEY_ALIAS`)।
কনটেন্ট বদলাতে শুধু `app/src/main/assets/www/data.js` বদলান, তারপর `node tools/check_data.js` চালিয়ে যাচাই করুন।
